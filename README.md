# Titanic Survival Analysis (R)

## Overview
Exploratory data analysis, feature engineering, and visualization of the Titanic dataset using R.

## Skills Demonstrated
- Data cleaning (dplyr)
- Feature engineering (family size, ticket size, age groups)
- Visualization (ggplot2)
- Handling missing values
- Basic statistics
- R Markdown-style structuring

## Project Structure
- titanic_analysis.R — main analysis script
- plots/ — saved visualizations
- data/ — dataset (if allowed)

## Key Findings
- Survival rate varies strongly by class and gender.
- Age distribution differs between survivors and non-survivors.
- Family size and ticket group size show meaningful patterns.
